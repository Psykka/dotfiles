# dotfiles

My SwayFX configs on Fedora.

```sh
git clone git@github.com:Psykka/dotfiles.git ~/dotfiles
cd ~/dotfiles && stow -t ~ sway waybar mako fuzzel swaylock alacritty gtk fonts keyboard spotify
```

`Super + /` shows all keybindings.
